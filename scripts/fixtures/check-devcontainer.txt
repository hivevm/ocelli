# Cases of scripts/check-devcontainer.sh, read by scripts/test-check-devcontainer.sh.
#
# One case per line, four fields separated by ' | ':
#
#   <pass or fail> | <what the output holds, or -> | <name> | <tree>
#
# A run exits 0 for pass and 1 for fail. The second field is '<key>', then ' @ <subject>' for each
# datum the line names, such as the clause. A line of the output ends in '[<key>]', the rule and a
# reason word, and holds each subject, in that order and with no ASCII letter, digit, hyphen,
# or underscore beside it; the rest of its wording is free.
#
# A line that starts with '#' is a comment, not a case. The subjects are looked for in the part of
# the line before its key, so that none holds by the key alone. A field may start with '!': it then
# holds where no line that ends in '[<key>]' holds the subjects in their order, so a field
# '!<key> @ <a> @ <b>' is not broken by a line that names <b> before <a>.
#
# The tree is a list of steps separated by '; ', or '-' for none, applied in order to a repository
# that passes the check, not under git, of three files. .devcontainer/devcontainer.json:
#
#   {
#     "name": "fixture",
#     // A comment: the container has no socket mount.
#     "image": "mcr.microsoft.com/devcontainers/base:debian",
#     "postStartCommand": <post>,
#     "features": {
#       // The one Feature.
#       "ghcr.io/devcontainers/features/github-cli:1": {}
#     },
#     "customizations": { "vscode": { "extensions": [] } }
#   }
#
# where <post> is the one line
#
#   { "hooks": "git config core.hooksPath .githooks", "merge": "git config merge.ff false && git config pull.ff only", "index": "git config merge.adr-index.driver '.githooks/merge-adr-index %O %A %B %S %X %Y'" }
#
# .devcontainer/devcontainer-lock.json:
#
#   {
#     "features": {
#       "ghcr.io/devcontainers/features/github-cli:1": {
#         "version": "1.0.0",
#         "resolved": "example@sha256:0000",
#         "integrity": "sha256:0000"
#       },
#     }
#   }
#
# .vscode/settings.json:
#
#   {
#     // Keep the container-management extension on the host side.
#     "remote.extensionKind": { "ms-azuretools.vscode-containers": ["ui"] }
#   }
#
# The steps:
#
#   rm <path>                   the file or directory removed
#   extra <json>                the json as one more top-level line of devcontainer.json, before
#                               the features block and after the lines of earlier extra steps
#   post [json]                 the json as the value of postStartCommand, or no such line when
#                               no json is given
#   feature <id>                the id as the one Feature of devcontainer.json, in place of
#                               ghcr.io/devcontainers/features/github-cli:1
#   lock <id>...                devcontainer-lock.json written again, resolving each id of the
#                               space-separated list in order, each as the base resolves its one
#   settings <json>             .vscode/settings.json written again, the json as the value of
#                               remote.extensionKind
#   write <path> <text>         the file written with exactly the text, each '\n' in it a line break;
#                               the text is all of the step after the path and the one space that
#                               follows it, leading spaces kept
#
# Each extra, post, and feature step writes devcontainer.json again: the base with the change of
# every such step of the case so far. In a step, '<pad N>' stands for N times the letter z.
