# Cases of scripts/sensor-plain-rules.sh with '--require', read by scripts/test-sensor-plain-rules.sh.
#
# One case per line, four fields separated by ' | ':
#
#   <pass or fail> | <what the output holds, '!' and what it lacks, or -> | <name> | <tree>
#
# The second field is '<key>', then ' @ <subject>' for each datum the line names: a file and line,
# or a term in double quotes. A line of the output ends in '[<key>]', the rule and a reason word,
# and holds each subject, in that order and with no ASCII letter, digit, hyphen, or underscore
# beside it; the rest of its wording is free. With '!', no such line stands. Where a case is about
# the place of a finding, its subject '<file>:<line>' decides that place.
#
# A line that starts with '#' is a comment, not a case. The subjects are looked for in the part of
# the line before its key, so that none holds by the key alone. A field may start with '!': it then
# holds where no line that ends in '[<key>]' holds the subjects in their order, so a field
# '!<key> @ <a> @ <b>' is not broken by a line that names <b> before <a>.
#
# The tree is a list of steps separated by '; ', applied in order to a git repository with the
# branch main of one commit and the branch 'work' off it, checked out. The commit holds:
#
#   AGENTS.md                '# Agent Guide', then '## 1. Rules' with the two items
#                            '- The human decides.' and '- Old line that says should.'
#   docs/adr/FIX-rule-x.md   '# FIX-rule-x: X', '- **Status:** 🟢 accepted', and '## Context',
#                            '## Decision', and '## Enforcement', each with the paragraph
#                            'The human decides.', a blank line between any two of these lines,
#                            so that the paragraphs stand on lines 7, 11, and 15
#   docs/adr/NUC:rule-y.md   the same, headed '# NUC:rule-y: Y'
#
# The sensor runs as '--require main' on the branch's commits, reading the change against main.
#
#   add <file> <section> <text>   a blank line and the text right after the heading of the section,
#                                 Rules for the one of AGENTS.md, committed; '\n' in the text breaks
#                                 the line
#   glossary <name>               docs/GLOSSARY.md, committed: '# Glossary', the paragraph 'One term
#                                 per concept; list under _Avoid:_ the synonyms it displaces.', and
#                                 after a blank line each <line> of the lines '= <name> | <line>', so that they start on line 5
#   base                          main moved to the branch's commit
#   rename <from> <to>            docs/adr/<from>.md moved to docs/adr/<to>.md, its heading naming
#                                 <to>, committed
#   takeup                        the NUC- files, the blob list, and AGENTS.md of this repository
#                                 copied over the fixture's, committed, as a take-up does
#   noflag                        the sensor run without '--require'
#
# A sensor run passes with exit code 0 and fails with exit code 1. In a case, 'NUC:' reads as
# 'NUC-', so that scripts/check-docs.sh reads no reference to an ADR here.
